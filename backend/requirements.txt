# LexiMind backend dependencies (Python 3.11)
#
#   python -m venv venv
#   venv/Scripts/pip install -r backend/requirements.txt
#
# Direct dependencies only — transitive ones are left to the resolver so this
# file stays readable. Versions are pinned to what M1/M2 were built and
# verified against.
#
# ── Non-pip prerequisites ─────────────────────────────────────────────────
# Java 8+      grammar checking (F27) runs LanguageTool, which is a Java
#              program. Without it /nlp/check still returns spelling and
#              homophone results and reports grammar_available: false.
#              Windows: winget install EclipseAdoptium.Temurin.21.JRE
#              On first use language_tool_python downloads LanguageTool
#              (~259 MB) into its own cache; expect a ~60s first startup.
#              If java is installed but not on PATH, set JAVA_HOME in
#              backend/.env — dotenv loads before the NLP service starts.
# Poppler      pdf2image shells out to it for PDF page rendering (F05).
#
# Downloaded at runtime on first use, no action needed:
#   - NLTK cmudict (syllable counts in routers/reading.py)
#   - EasyOCR detection/recognition models (~100 MB, first OCR call)
